## Summary of Review Findings & Status

The adversarial pass uncovered **4 P0 defects** and **5 P1 edge-case defects** introduced or left incomplete across PR #9 and PR #10 (plus 1 architectural coordination gap documented in PR #8). All 9 findings are documented below with exact `file:line` references and resolved in follow-up commits on PR #9 and PR #10.

| ID | PR | Sev | Location | Finding Summary | Resolution |
|---|---|---|---|---|---|
| **R-P0-1** | #9 | **P0** | `src/exchanges/hyperliquid_live.py:408-421` | `_call_exchange_order` wrapped `to_thread(self._exchange.order, ..., cloid_obj)` in `except TypeError:` and fell through to a 2nd `self._exchange.order(...)` call. Any internal `TypeError` raised inside SDK response handling after HTTP POST would submit a **duplicate live order without `cloid`**. | Inspect `inspect.signature(self._exchange.order)` *before* invoking; never catch `TypeError` around a live order network call. |
| **R-P0-2** | #9 | **P0** | `src/core/execution.py:965-1002`<br>`src/core/engine.py:4292-4311` | On a partial IoC close (`ORDER_PARTIAL`), `close_position()` updated `_open_trades` and SQLite `size=residual_sz` then raised `LiveExecutionError`, causing `_execute_exit()` to abort before updating `PortfolioState`. `PortfolioState` kept the old full size (`2.0` vs `1.5` on exchange), triggering an immediate `ExchangeReconciler` `mismatch -> HALT` within 60s and dropping the partial slice's realized PnL. | Add `PortfolioState.reduce_position_partial()` and call it inside `ExecutionEngine.close_position()` with proportional `entry_fee` accounting. |
| **R-P0-3** | #10 | **P0** | `src/multileg/coordinator.py:356-384` | `close_episode_taker()` did not parse the return value of `place_spot_order(order_type="ioc")` or `place_aggressive_limit(reduce_only=True)`. A rejected or partially filled IoC close still decremented `leg.filled_size = 0` and marked `ep.status = "closed"`, orphaning live exposure. | Validate every close response via `parse_hyperliquid_close_response(..., expected_size=close_qty)`; credit only confirmed filled size and keep `status = "pending_exit"` (raising `RuntimeError`) if incomplete. |
| **R-P0-4** | #10 | **P0** | `src/multileg/coordinator.py:345-366`<br>`src/multileg/carry_adapter.py:72-78` | On Hyperliquid Spot, `BUY` fees (`0.015%` maker / `0.045%` taker) are deducted in the **base token** unless fee rebates/discounts apply (`19.98 HYPE` bought yields `19.977 HYPE` -> `19.97` truncatable). Attempting to `SELL 19.98 HYPE` on exit rejects on HL with `Insufficient spot balance`. | Query `get_available_spot_balances()` before live Spot sells, clamp `close_qty` to available base token balance, and treat post-fee dust (`<= 0.2%` of target) as fully closed; gross-up entry Spot buy by `1 / (1 - MAKER_FEE_RATE)` when tick rounding permits. |
| **R-P1-1** | #9 | **P1** | `deploy/linux/dashboard_proxy.py:55-68` | `first_chunk = True` only rewrote the first `recv()` chunk per TCP socket: (a) on HTTP/1.1 keep-alive, a 2nd request on the same TCP socket bypassed `rewrite_http_head` (`_is_direct_local_request() -> True` auth bypass!), and (b) fragmented TCP headers split before `\r\n\r\n` bypassed rewriting. | Accumulate initial request bytes until `\r\n\r\n` (up to `64 KiB`) and inject `Connection: close` on non-WebSocket HTTP requests from non-loopback peers so only 1 HTTP request can traverse each TCP connection. |
| **R-P1-2** | #9 | **P1** | `src/core/engine.py:4589-4595` | Positions opened *before* upgrading to PR #9 and restored via `PortfolioState.from_dict()` lack `metadata["entry_fee_debited"]`, so their first post-upgrade close would still double-deduct `entry_fee` once. | Backfill `entry_fee_debited` from `trade.entry_fee` in `_sync_open_trades_to_portfolio()` even when `trade.symbol in current`. |
| **R-P1-3** | #9/#10 | **P1** | `src/core/reconciliation.py:160-172` | If single-leg `TradingEngine` (`orphan_exchange_policy = HALT` on Mainnet) shares the same HL wallet as `MultiLegCoordinator`, `ExchangeReconciler` sees `MultiLegCoordinator`'s perp leg on HL, finds it absent from single-leg `PortfolioState`, and triggers `orphan_exchange -> HALT` (or `FLATTEN`). | Add `ignored_symbols_provider` to `ExchangeReconciler` (plus helper reading active perp symbols from `multileg.db`) so managed multi-leg perp symbols are skipped cleanly. |
| **R-P1-4** | #10 | **P1** | `src/multileg/coordinator.py:104-125` | `ensure_margin_ready()` checked gross `marginSummary.accountValue` and total `USDC` spot balance without subtracting `totalMarginUsed` or spot `hold` amounts, allowing a second episode to pass pre-flight when capital is already locked in Episode 1. | Check free collateral (`withdrawable` or `accountValue - totalMarginUsed`) and available Spot `USDC` (`total - hold`). |
| **R-P1-5** | #10 | **P1** | `src/multileg/ledger.py:180-200` | `MultiLegLedger` wrote episodes/legs to SQLite (`save_episode`) and listed raw dicts (`list_episodes`), but lacked `load_active_episodes() -> List[MultiLegEpisode]` to hydrate live `MultiLegEpisode` + `LegState` + `CarryMarginParams` objects after a container restart on `bots-01`. | Implement `MultiLegLedger.load_active_episodes()` and test full crash/reload continuity. |

## Verified Non-Issues (Hypotheses Tested & Cleared)

1. **`normalize_price` vs `hyperliquid.utils.signing.float_to_wire`:** Empirically fuzzed across `is_spot in {False, True}`, `szDecimals in 0..8`, and prices from `$0.000004567` to `$105,432.78` (`216` combinations) — **0 `float_to_wire` exceptions and 0 `>5` sig-fig violations**.
2. **`PortfolioState._cash < 0` under leveraged `sync_live_account_equity`:** Grep across `src/core/risk_manager.py` and `src/core/portfolio.py` confirmed sizing and drawdown gates read `get_total_value()` / `_total_equity()` (`self._cash + allocated_notional + unrealized == acct`), never requiring `self._cash > 0`.
3. **Unlegged adverse excursion sign (`coordinator.py:424-428` vs `PREREGISTER_CARRY_SHADOW.md §10`):** Pending `buy` leg records `(mid - ref) / ref` (positive bps when price runs away upward); pending `sell` leg records `(ref - mid) / ref` (positive bps when price drops away downward) — **exact match**.
